| `modal.js` | The full-image dialog around `viewer.js`: one box (`openModal`: prev / next through the gallery order, find similar, boxes in this image, its group), one whole image (`openImage`: the image browser's order), or a prediction with no label box (`openPredModal`, a false positive, server-drawn). | `model.js` | The **Model** tab: pick a saved model, run it on the dataset (job with progress), score it at a confidence / match IoU / split (val by default). Left: KPIs + per-class table. | `eval.js` | The **Evaluation** tab. It compares every model that ran on the dataset: a sortable leaderboard (each model at its best-F1 confidence, or one fixed threshold), speed against accuracy, and AP50 per class × model. It explains one model with the dataset: training labels vs AP, train vs val gap, per session, calibration, box fit, model vs kNN agreement, box sizes and worst images. Data: `GET /api/eval/overview`. |

## How it is written

- **`setSelection(ids, title, opts)` is the only way to change the gallery.** It updates `S.sel`,
  the highlight rings and the picks, and clears the lasso unless `keepLasso`.
- `loadView()` uses a **sequence number** (`viewSeq`). If a newer request starts while one is waiting
  on a job, the stale one drops its result instead of overwriting the newer view.
- Settings restore skips the controls that pick *which* projection is shown (`VIEW_IDS`), so a page
  load always opens the fast startup view rather than starting a long job.
- Accessibility: chips and cards are `role="button"` with Enter / Space handling. Toggles use
  `aria-pressed`, and the splitter is keyboard-resizable with ← and →.

## Techniques

- **Gallery paging.** Only `UI.page_size` (default 100) cards are in the DOM, and the thumbnails use
  `loading="lazy"`.
- **Delegated events.** The gallery, chips, pager and class table each have one listener for any
  number of items.
- **Throttled resize while dragging the splitter.** Re-flowing a large WebGL plot is expensive, so it
  runs at most every 100 ms, plus once on release.
- **Class filter.** A click toggles a class, and a double-click shows only that class. The single
  click waits 220 ms, so a double-click doesn't also toggle.
