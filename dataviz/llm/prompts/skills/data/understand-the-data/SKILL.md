---
name: understand-the-data
when: the user asks what a table holds, or you meet a table you do not know
description: Learn what a table holds before answering
---
1. `describe_table`, and read the descriptions.
2. `run_query` with a limited SELECT, then `profile_result`.
3. Note empty columns, ID-like columns and coded values. Ask about the coded ones.
4. Summarise what the table is for in plain words.
