title: The builder board's notes
summary: zones, text labels, sticky notes and shapes on the Visual builder board; rotate, lock, colours, text position, Auto zones, read_board / edit_board

---
- The Visual builder board holds **notes** next to the table cards, so a schema can be explained in zones. One kind of element covers all of them: a **zone** is a shape behind the tables (layer back) with a light fill and a title; **text** is a shape with no fill or border; a **sticky note** is a filled shape in front; other shapes are ellipse, diamond, hexagon, callout (speech bubble) and pill. A background box with no text is just a coloured zone. Notes never change the SQL and are saved with the query tab (undo covers them).
- **Add**: **+ Note** bottom-right on the board (Zone, Text, Title, Sticky note, shapes, Auto zones), or right-click an empty spot of the board to add one there.
- **Move and size**: every note, zones too, **drags from anywhere on it** (tables sit above zones, so they still click and drag on their own); a selection box starts on empty board outside the zones (or Shift-click tables to add them), and right-drag pans anywhere. With **Move cards with zone** (on for new zones) dragging a zone moves the tables inside it; Alt+drag moves the zone alone. Handles resize a selected note. Moves snap to 8 px (Shift: free). Arrows nudge (Shift: 8 px).
- **Rotate**: every note (zones, text, sticky notes, shapes) turns about its centre. Drag the round handle above a selected note (free, held at 0° / 90° / 180°; Shift: 15° steps; the angle shows while turning); double-click that handle to straighten. The format bar has ↺ ↻ (15°) and a degrees box (-180..180); [ and ] turn the selection 15° (Shift: 1°); right-click: Rotate 90°, Straighten. A rotated note still resizes along its own sides, and a rotated zone with Move cards with zone carries the cards inside its turned shape. Locked notes do not turn.
- **Text**: double-click a note to write in it; Esc cancels, Ctrl+Enter or a click outside keeps it. The format bar's 3×3 grid puts the text top / middle / bottom × left / centre / right.
- **Format bar** (above the selected notes): shape, 8 colours plus any colour and No fill, fill opacity, border solid / dashed / none, text size A− A+, bold, text position, Bring to front / Send to back, Move cards with zone, rotation, **lock**, duplicate, delete. Right-click a note: Edit text, Lock, Duplicate, Front / back, Rotate 90° / Straighten, Delete.
- **Lock** (format bar, right-click, Ctrl+L): a locked note does not move or resize (a click only selects it, so it can be unlocked); Delete asks first. Only the user locks and unlocks.
- **Auto zones**: one zone per group of joined tables (all joined: one per schema), each in its own colour with a label; running it again replaces the earlier auto zones, not the user's own notes.
- **Table descriptions**: a description note is a sticky note pinned to a table card: it sits above the card and moves with it when the card is dragged.
- **You** can see the board with `read_board` (tables with their positions, sizes and catalog descriptions, joins with 1:N / N:M, notes with ids; "describes" = the table a description note belongs to) and change it with `edit_board`, one undo step for the user: a zone op {label, tables} draws a zone around tables, a describe op {table, text} pins a description above a table, arrange true moves the cards zone by zone so zones do not overlap (the SQL never changes); the page measures and places all of these, so you give no coordinates. add / update / remove change one note by id; note.rot turns it (degrees clockwise, -180..180, 0 = straight; x, y, w, h stay the unrotated box), and read_board shows rot on turned notes. A zone op always draws its zone straight. You cannot lock or unlock, or touch a locked note. Keep labels short and descriptions to one or two sentences.
