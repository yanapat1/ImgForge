- **Layout**: the same header as every page (Dataset Visualizer, Sessions · Data · Analysis, settings, theme), the session name next to the links. On the left an activity bar: Query, Catalog, Scripts, Analyze, Dashboards, History, and at its bottom the button that shows or hides the **Objects** panel (connections, databases, tables). The « on its header folds it away to a slim **Objects** strip in its place; a click anywhere on the strip unfolds it; Ctrl+B toggles it too, and dragging its edge far to the left closes it (remembered in this browser). Drag the Objects panel's right edge to widen it for long table names (remembered in this browser); double-click the edge to fit the longest name shown, or focus it and use ←/→ (Shift = bigger steps), Home = default width. Hovering a table shows its full name. The look follows the UI sheet (Settings › Appearance › Open the UI sheet).
- **Favorites** (top of the Objects panel): the ☆ beside a table (shown on hover) stars it; right-click a table for Add to / Remove from Favorites, Move to category, New category…. Categories are the user's own groups: + on the Favorites header makes one, ⋯ on a category renames, reorders or deletes it (its tables stay in Favorites), and a table dragged onto a category header goes there. A favorite works like the tree row (click = columns, double-click = query, drag = builder). Kept per user across sessions and browsers; up to 300 tables and 40 categories (names up to 60 characters). You see the category names (the scope line) and read a category's tables with `list_favorites`; `search_catalog` marks a hit that is a favorite with its category. You cannot change favorites: tell the user where to click.
- **Catalog**: one table's columns, types, keys and relationships. Descriptions the user writes stay in this app and you read them, so better descriptions give better answers. Writing them: each box saves when the user leaves it; Tab or Enter moves to the next column's box, Shift+Enter or ↑ goes back, Ctrl+Enter jumps to the next empty one, Esc undoes the edit.
- **Scripts**: named command boxes kept with the session. Coming back shows them; nothing runs until Run all, and changes confirm first.
- **Temp tables** live on the session's connection and show with a ⏱ mark in the Objects panel. They go when the user closes the session, or 15 minutes after the page is gone. A refresh loses nothing. After a server restart, rerun the script.
- **Analyze** works on the open tab's last result: Profile, Statistic tests, Data quality, Pivot, Forecast (see Forecast).
- **Dashboards**: tools KPI number, Bar, Ranking (horizontal bars, largest first), Line, Area, Donut (each group's share, with a legend), Forecast, Table (with share bars), Text box. Drag fields onto a widget (on a KPI the field is its number), drag a widget to swap places. Click a widget's header to edit it in the side panel: Title, Kind (switch a chart to another kind), X / Y wells, Using (sum, avg, min, max, count), Order (natural, largest first, smallest first) and Show (top 5..100 groups: the top groups by value, not the first by name), Width (quarter to full), Height (short, medium, tall), Colour (accent or 8 colours). The header's buttons duplicate or remove it. A KPI is exact over the whole result; with a Trend by field it draws a sparkline. Toolbar: dashboard picker, Rename, New, Delete (asks first), Build from this result (KPIs, an area trend, a donut, a forecast, a ranking and a bar), Refresh, Present (full screen, Esc leaves), Clear (asks first). Charts read the last result, so they need a run after the session reopens; each chart's data is fetched once per result.
- **History** keeps every run's text, searchable, and Open puts it in a new tab.
